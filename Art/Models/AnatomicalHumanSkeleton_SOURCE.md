# Anatomical human skeleton source and build

This asset is an adaptation of individual anatomical polygon surfaces from
[BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/), not a sculpt
made from generic mesh primitives. The source data describes one adult male
anatomical reference in millimetres. The build uses 254 separate bone and
costal-cartilage reference surfaces, scales their assembled height to 1.78 m,
rotates the arm and hand surfaces into a neutral T pose, welds duplicate OBJ
seams, and reduces polygons on each named structure individually. The cervical
vertebrae retain more polygons; C3–C6 spinous tips are tapered after reduction
to preserve their profile. A custom polygon cage extends the measured sacral
apex into a coccyx because the reference set has no separate coccyx.

Source meshes: BodyParts3D 4.3, accessed via the
[mesh repository](https://github.com/olivercase/body_parts_3d_api). See the
[official BodyParts3D license](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)
for the current terms. Required attribution when distributing the adapted
asset: **BodyParts3D, © The Database Center for Life Science licensed under CC
Attribution 4.0 International**. The geometry has been scaled, posed, welded,
and reduced for this project.

The editable model is `AnatomicalHumanSkeleton.blend`. The frontal, sphenoid,
ethmoid, lacrimal, palatine, and zygomatic source surfaces retain extra polygons
around the orbital walls. The cranial and maxillary surfaces are then fused in
a single 0.8 mm voxel polygon pass, closing unintended joins in the orbital
floor and above the upper teeth while retaining the natural nasal aperture and
small posterior orbital openings. The mandible keeps its measured alveolar
crest. Each tooth is clipped near its
local jaw crest so hidden roots do not consume game polygons. A closed,
tooth-contour-derived socket rim is lofted around each visible crown, scalloped
between adjacent teeth, and fused into the corresponding jaw bone with a fine
0.6 mm polygon remesh. The skull plus upper crowns is one
`Skull_with_Upper_Teeth` mesh; the mandible plus lower crowns is a second
`Mandible_with_Lower_Teeth` mesh. The crowns use a distinct smooth enamel
material. Other bones remain separate under `SKELETON_ROOT`. The Unity import asset is
`Assets/Art/3d Models/Characters/Undead/AnatomicalHumanSkeleton.fbx`.
The 20 separate costal cartilages restore the front of the ribcage: ribs 1–7
connect to the sternum through their own cartilage, ribs 8–10 form the lower
costal margin by joining the cartilage above, and ribs 11–12 remain floating.
They are anatomical surfaces from the same reference set, not extruded tubes.
The six open lower-cartilage source surfaces are closed with a fine polygon
remesh before their final game-mesh reduction.
`AnatomicalHumanSkeleton_measurements.csv` records each reference structure's
source bounding dimensions in millimetres, its final bounding dimensions in
metres, and its polygon count. Run `build_anatomical_skeleton.py` in Blender to
rebuild the model; it downloads missing references to the system temporary
directory.

The bone PBR set is under `Assets/Art/Textures/Bone/`:
`Bone_BaseColor.png` is an image-generated warm-ivory diffuse tile (no baked
lighting); `Bone_Normal.png`, `Bone_Roughness.png`, and
`Bone_MetallicSmoothness.png` are tileable technical maps generated by
`build_bone_pbr_maps.py`. The last map packs zero metallic into RGB and
smoothness into alpha for Unity URP Lit. Run that script before the skeleton
builder when regenerating maps; the generated albedo must already be present.
The model has metre-scaled box-projected `BoneUV` coordinates with a 0.1 m
texture tile. Blender uses the albedo, roughness, and normal maps in
`Bone_PBR`; Unity uses `Assets/Art/Material/Bone_PBR.mat` with the albedo,
normal, and packed metallic/smoothness map. `Tooth_Enamel.mat` is the separate
low-metallic, smoother enamel material. Both are remapped to the imported FBX.

The FBX contains geometry, UVs, and two material slots on skull and jaw, but
no armature or skin weights. Bone meshes retain separate pivots so they can be
bound to a game rig; the skull and jaw have their own rotation origins.
The current asset has 206 meshes and 39,966 triangles. The orbital wall layout
follows the seven-bone anatomy described by
[NCBI Bookshelf's orbit-bone reference](https://www.ncbi.nlm.nih.gov/books/NBK531490/).
