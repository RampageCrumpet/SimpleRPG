# SimpleRPG.AudioModel

The data of sound: audio event definitions, tables, tags, contexts, profiles, and the small pure helpers that read them (`IAudioRandom`, `MovementLayerPicker`).

**Does not belong here:** anything that plays a sound. Playing belongs in `AudioPlayback`.

Layering rules and the full table: `Docs/CodeLayout.md`. The layering is enforced by `AssemblyLayeringTests`.
